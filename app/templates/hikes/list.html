{# ============================================================ Template: hikes/list.html Extends: base.html Purpose: Public catalog of all Challenge Hikes as a responsive card grid. Each card shows a small (180px) Leaflet map preview of the hike's route, the hike name, the date it was posted, a status pill (newest / open / upcoming), distance / elevation stats, and a duck tally overlay on the map (always rendered, "×0" included). Read the status pill carefully: "open" does not mean "still open for now" and "newest" does not mean "the only one you can do." Every posted hike is open permanently; the pill only distinguishes the current headline from the rest of the catalog, and flags the hikes that have not dropped yet. Maps on the cards are thumbnails — all interactions disabled so they don't fight page scroll. To see the interactive route and elevation profile, the user clicks through to the hike detail page. For logged-in users who've earned a duck on a hike, the card also shows a "you've completed this hike" note inside the body. Variables passed in from hikes.catalog(): - hikes: list of sqlite3.Row from list_hikes(), each row carrying duck_count (SUM of counts — what the duck icon shows) and completion_count (row count — what the word "completions" means) - today: today's ISO date string for status comparisons - featured_id: id of the newest posted hike, or None - completed_hike_ids: set of hike IDs the logged-in viewer has completed (empty set when anonymous) ============================================================ #} {% extends "base.html" %} {% block title %}Hike catalog — CocoSAR Mountain Rescue Challenge Hikes{% endblock %} {% block head_extra %} {# Leaflet for the per-card map thumbnails.
